## State vocabulary

1. `UNKNOWN` — no connectivity information has ever been received for the device/profile.
2. `PROVISIONED` — connectivity profile conceptually associated; reachability not yet confirmed.
3. `REACHABLE` — connectivity path currently confirmed responsive.
4. `UNREACHABLE` — connectivity path currently not responding; cause not yet classified.
5. `DEGRADED` — connectivity path responsive but reduced quality without being fully unreachable.
6. `SUSPENDED` — intentionally paused by administrative action; not a fault.
7. `DECOMMISSIONED` — device/connectivity profile retired and no longer expected to report.
