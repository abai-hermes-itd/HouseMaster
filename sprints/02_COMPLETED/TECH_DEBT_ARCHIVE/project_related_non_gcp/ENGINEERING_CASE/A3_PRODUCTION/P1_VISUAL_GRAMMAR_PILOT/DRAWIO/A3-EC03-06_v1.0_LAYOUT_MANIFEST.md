## Dominant visual

Seven-row failure-domain matrix with fixed columns:

1. FAILURE DOMAIN
2. RESPONSIBILITY LAYER
3. OBSERVABLE EFFECT
4. DATA / CONNECTIVITY CONSEQUENCE
5. WHAT REMAINS OPERATIONAL
6. WHAT IT DOES NOT PROVE
7. RECOVERY / NEXT CHECK

Rows remain separate and in frozen order:

- F-01 PHYSICAL DEVICE FAILURE
- F-02 LOCAL POWER FAILURE
- F-03 LOCAL EDGE / AGGREGATION FAILURE
- F-04 ACCESS / RADIO CONNECTIVITY FAILURE
- F-05 OPERATOR TRANSPORT FAILURE
- F-06 HOUSEMASTER INTEGRATION EDGE FAILURE
- F-07 HOUSEMASTER PROCESSING FAILURE

## Responsibility encoding

- F-01: BUILDING / FIELD — neutral responsibility cell
- F-02: BUILDING / FIELD — neutral responsibility cell
- F-03: BUILDING / FIELD or JOINT if operator-managed — shared-boundary cell
- F-04: TBD WITH BEELINE — STATUS-TBD-BEELINE cell
- F-05: BEELINE — DOMAIN-BEELINE cell
- F-06: HOUSEMASTER — DOMAIN-HOUSEMASTER cell
- F-07: HOUSEMASTER — DOMAIN-HOUSEMASTER cell

Responsibility colors encode responsibility only, not severity or engineering condition. Failure-domain labels use STATUS-RISK because the rows represent genuine failure classes.

## Visual axiom

`F-01 ≠ F-02 ≠ F-03 ≠ F-04 ≠ F-05 ≠ F-06 ≠ F-07`

`ALL FAILURE DOMAINS ≠ ENGINEERING COMPONENT FAILURE ≠ BUILDING FAILURE`

No connector maps a failure-domain row into engineering or building state.

## Support panel — connectivity states

Panel title: `HOUSEMASTER INTEGRATION STATES — NOT BEELINE INTERNAL NETWORK STATES`.

States:

- UNKNOWN
- PROVISIONED
- REACHABLE
- UNREACHABLE
- DEGRADED
- SUSPENDED
- DECOMMISSIONED

`UNREACHABLE = EXPECTED PATH NOT RESPONDING · ROOT CAUSE UNCLASSIFIED`.

UNREACHABLE is not connected to any single failure-domain row.

## Support panel — timing / store-and-forward

`event_time CREATED → LOCAL BUFFER / STORE → TRANSPORT UNAVAILABLE → CONNECTIVITY RESTORED → BUFFERED OBSERVATION FORWARDED → received_time CREATED`

Prominent constraints:

- event_time ≠ received_time WHEN BUFFERED
- DELAYED DELIVERY DOES NOT REWRITE event_time
- CONNECTIVITY LOSS MAY CREATE TEMPORARY EVIDENCE GAP
- CONNECTIVITY LOSS ≠ ENGINEERING FAILURE

Unresolved values remain `NOT DEFINED`: buffer size, retention period, retry interval, heartbeat, timeout and polling frequency.

## Guardrails

- DEVICE OFFLINE ≠ COMPONENT FAILED
- EDGE OFFLINE ≠ BUILDING FAILURE
- NETWORK HEALTH ≠ BUILDING HEALTH
- CONNECTIVITY STATE ≠ ENGINEERING STATE

## Frozen constraints

- No failure domains, responsibility mappings, states, timing semantics, store-and-forward semantics or guardrails are changed.
- No root cause is assigned to UNREACHABLE.
- No internal operator topology, RF threshold, retry/heartbeat/timeout value, SLA, monitoring product, alarm or device hardware is shown.
