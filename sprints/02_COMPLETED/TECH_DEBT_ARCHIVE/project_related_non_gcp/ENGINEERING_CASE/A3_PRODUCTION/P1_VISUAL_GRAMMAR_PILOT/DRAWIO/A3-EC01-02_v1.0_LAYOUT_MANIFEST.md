## 10. Wrap / spacing decisions

- `TITLE_THESIS` wraps within a 300mm box at 9.5pt — full sentence fits in
  2 lines without truncation.
- Evidence-rail field values use a simple heuristic (`~48 chars per line at
  8pt` → estimated line count → box height) to size each value box; this
  is a layout convenience only, not a semantic decision, and may be
  re-tuned freely in a future visual-only patch.
- `FOOTPRINT_CAPTION` is placed to the right of the schematic shape rather
  than below it, to keep the whole footprint block within the 101mm zone
  height without compressing the shape itself.
- No text anywhere on this page falls below the TYPE-FOOTER floor (7.5pt).

## 11. What a future patch may change without reopening the IR

Per `GRAPH_COMPILER_RULES.md` §D and this task's §1: any x/y/width/height
value above, guardrail grid arrangement, evidence-rail field box sizing,
footprint-schematic rectangle positions (as long as the stepped character
remains visually legible and no dimension/scale/area is added), and text
wrap points.

**May not** be changed without reopening the semantic gate: any fact value
or status token in §4/§6/§7, any guardrail wording, the do_not_imply list,
the "PARTIAL / SCHEMATIC" footprint label, or the LEFT=identity/
RIGHT=provenance zone assignment.
