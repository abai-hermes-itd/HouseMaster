# HouseMaster Sprint Operations

This folder contains operational sprint management materials for the HouseMaster project.

## Structure

| Folder | Purpose |
|---|---|
| `00_ROADMAP` | Long-term sprint roadmap and release plan |
| `01_ACTIVE` | Current active sprint materials |
| `02_COMPLETED` | Closed sprint reports and summaries |
| `03_PIPELINES` | CI/CD, deployment, Cloud Build, Terraform pipeline notes |
| `04_RUNBOOKS` | Operational runbooks and preflight gates |
| `05_CLAUDE_TASKS` | Task prompts and implementation instructions for Claude |
| `06_CHATGPT_ORCHESTRATION` | Architecture/orchestration notes from ChatGPT |
| `07_DECISIONS` | Operational decisions that do not require ADR |
| `99_ARCHIVE` | Deprecated or superseded sprint materials |
