# infrastructure/

Каталог зарезервирован под инфраструктурную конфигурацию приложения. Код появится на фазе «Развёртывание в GCP» (см. roadmap в `docs/architecture/000-system-overview.md`).

| Каталог | Назначение |
|---|---|
| `terraform/` | Связка с инфраструктурным Terraform-репозиторием: ссылки на модули, tfvars-контракты окружений. Основной Terraform-код живёт в **отдельном репозитории** (ADR-0001, ADR-0002) — здесь только то, что относится к самому приложению. |
| `cloudbuild/` | Дополнительные конфигурации CI: пайплайны воркеров, промоушен между окружениями. Основной пайплайн — `/cloudbuild.yaml` в корне. |

До соответствующей фазы каталоги намеренно пусты (`.gitkeep`).
